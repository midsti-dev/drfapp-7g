Here is the final project: MVP of django app

It contains reddis, postgres, django and celery worker. When you clone the project, just build it and you will be fine.

zsh: docker compose up --build -d

it will make your project run in detach mode, so you could continue using terminal for other things!


Your containers will run and you will be able to access by your localhost.

Also do check logs if you have some troubles.
